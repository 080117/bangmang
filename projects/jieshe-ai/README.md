## 本地运行

```bash
node app/server.mjs      # 本地版 → http://127.0.0.1:7788（含语音输入/朗读）
node web/server.mjs      # 部署版预览 → http://127.0.0.1:7789（无语音，走 OpenRouter）
```

首次使用在网页 ⚙ 设置里填入模型 API Key（本地版支持 DeepSeek / OpenRouter / 硅基流动 / 通义千问 / 自定义；部署版密钥放服务端环境变量，见 `docs/deploy-netlify.md`）。

## 部署到 Netlify

见 [docs/deploy-netlify.md](docs/deploy-netlify.md)：把 `web/`、`netlify/`、`netlify.toml` 一起拖到 Netlify Drop，配好 `OPENROUTER_API_KEY` 环境变量即可公开访问。
