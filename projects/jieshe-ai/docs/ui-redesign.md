# 戒社 AI 网站 UI 重设计说明（v2 设计交付文档）

> 设计师视角的完整交付说明：设计目标 → 参考视觉语言 → 设计系统 → 信息架构 → 三大功能逻辑匹配 → 交互规格 → 验证记录。
> 生效文件：app/public/index.html / style.css / app.js（前端三件套全部重写），app/server.mjs（仅做流中止与重新生成的加固，接口契约不变）。

## 一、设计目标（两大改造维度）

### 1. 完善架构（信息架构层面）
旧版问题：三大功能只是侧栏里的三个小标签，设置、热线、金句、主题全部挤在侧栏底部，移动端直接隐藏侧栏导致功能丢失；输入区、会话历史、危机提醒的层级关系不清晰。
新版解法（对齐 ChatGPT 的产品架构）：
- **侧栏 = 管理区**：品牌 → 新开会话 → 会话搜索 → 会话历史（按 今天/昨天/前7天/更早 分组）→ 工具区（他的声音金句试听 / 求助热线 / 模型与语音设置 / 主题切换 / 免责声明）。
- **主列 = 对话区**：顶部窄顶栏（菜单、会话标题、自动朗读、求助热线、主题）→ 危机横幅（自杀护栏）→ 居中 760px 对话列 → 悬浮胶囊输入区。
- **全局可达**：求助热线在顶栏与侧栏双入口（安全类产品必须一键可达）；危机横幅常驻于消息区上方，45 秒自动收起、可手动关闭。
- **响应式**：桌面端侧栏可折叠；≤900px 侧栏变为抽屉 + 遮罩，全部功能仍可用。

### 2. 逻辑匹配（三大功能 × 交互逻辑）
三个主要功能（忏悔室 / 问答 / 闲聊）现在拥有「一等公民」地位，映射关系：
- **入口**：输入区左下角的「模式选择器」（对齐 ChatGPT 的模型选择器位置与交互），弹出三张模式卡片（图标 + 名称 + 一句话定位 + 选中态）。
- **开场**：每个模式有自己的欢迎页（专属扁平插画 + 专属标题副标题 + 4 条专属建议卡片，点击即发送）。
- **状态**：每个会话记住自己的模式；侧栏历史条目带模式图标；空会话切换模式即持久化。
- **输入**：输入框占位文案随模式切换（「说出来吧，我听着…」/「想问点什么？直接问…」/「随便聊聊，别见外…」）。

## 三、设计系统：新拟物 × 扁平插画

### 3.1 风格策略
- **新拟物（Neumorphism）为骨架**：背景与元件同色系，靠双光源阴影做「挤出感」——外凸（按钮、卡片、输入胶囊）、内凹（搜索框、模式选择器、弹窗分区、插画底盘）。
- **扁平插画为点缀**：三个模式各一幅几何插画（忏悔室=烛火、问答=书本、闲聊=咖啡），置于内凹圆盘中，兼顾品牌温度与亲和力。
- **克制使用**：正文消息不做气泡（保证长文可读性与对比度），红色仅用于品牌与危险动作，金色用于强调。

### 3.2 设计令牌（tokens）
| 令牌 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| --bg / --surface | #e7ebf1 / #e9edf3 | #23262b / #262a30 | 底色与隆起面 |
| --surface2 | #e2e7ee | #2b3037 | 内凹/次级面 |
| --sh-raised | -7px 高光 + 7px 深影 | 同构（弱高光 + 深影） | 外凸元件 |
| --sh-inset / --sh-pressed | 内凹 / 按压 | 同构 | 凹槽与按态 |
| --accent | #c83c31 | #e2574b | 品牌红（按钮、激活、链接） |
| --gold | #9a6a1e | #dfae63 | 金句强调、热线号码 |
| --text / --dim / --faint | #2b313a / #5d6672 / #8a94a0 | #e8eaee / #a6afb9 / #7c8691 | 三级文字（对比度达标） |

### 3.3 无障碍与工程
- :focus-visible 焦点环、图标按钮 aria-label、危机横幅 role="alert"、prefers-reduced-motion 全关闭动画。
- 全部色值走 CSS 变量，暗色主题仅替换令牌，零散色硬编码仅在插画（通用粉彩，双主题均成立）。

## 五、交互规格（新增能力清单）

1. 流式对话：打字光标、贴底跟随、上翻即暂停跟随 + 回底按钮。
2. 停止生成：发送键变停止方块，AbortController 中止；服务端加 res close 检测，不再写半截消息进会话文件。
3. 重新生成：重发最后一条用户消息（replace 标志，服务端先弹出旧助手回复再追加，避免历史污染）；顺带修复了旧版本地消息重复追加的隐患。
4. 复制 / 朗读：每条助手消息可复制、可朗读（浏览器语音或音色克隆双引擎）。
5. 会话：按日分组、关键词搜索、删除需二次确认（同一按钮再点一次），首条消息自动生成标题。
6. 主题：亮/暗/自动三态，localStorage 持久化，自动模式跟随系统变化；顶栏按钮循环切换。
7. 危机护栏：消息流 meta.crisis 触发横幅（全国心理援助热线 12356 等），45 秒自动收起。
8. 快捷键：Ctrl/Cmd+N 新会话、Ctrl/Cmd+K 聚焦搜索、Esc 关闭弹层/抽屉、Enter 发送、Shift+Enter 换行。
9. 移动端：≤900px 侧栏变抽屉 + 遮罩；建议卡片单列；消息操作常显。
10. 语音：浏览器识别不可用自动降级本地 whisper（MediaRecorder → /api/asr），占位/按钮状态联动。
11. 金句试听：播放中图标与底色联动（▶ → ▣）。
12. 未配置 Key 时，输入区下方常驻提示「点左侧 ⚙ 设置」，配置后面自动恢复免责声明。
